# 서든어택 최적화

윈도우 설정을 서든어택에 맞게 **버튼 한 번**으로 바꿉니다.
그리고 바꾼 값을 전부 적어두기 때문에 **언제든 원래대로 되돌릴 수 있습니다.**

> 게임 파일은 건드리지 않습니다. 윈도우 설정만 바꿉니다.

---

## 0. 받는 법 · 쓰는 법

### 가) 나눠줄 때 — exe 하나 (파이썬 필요 없음) ⬅ 보통은 이것

**[Releases](../../releases/latest)** 페이지 → **Assets** → **`SuddenAttack-Optimizer.exe`**

이 파일 **하나만** 친구에게 주면 됩니다. 설치할 것도, 파이썬도 필요 없습니다.
(윈도우 10 / 11, 64비트)

더블클릭하면 이렇게 진행됩니다.

1. **"Windows의 PC 보호"** 파란 창 → **추가 정보** → **실행**
   (돈 주고 산 서명 인증서가 없는 프로그램이라 뜹니다. 개인이 만든 무료 프로그램은 대부분 뜹니다.)
2. **"이 앱이 디바이스를 변경하도록 허용하시겠어요?"** → **예**
   (**아니요**를 눌러도 뜹니다. 대신 전원·네트워크 항목이 잠기고, 자동 적용도 하지 않습니다.)
3. 브라우저에 화면이 뜹니다 (`http://127.0.0.1:8770`)
4. **처음 실행이면 — 이 컴퓨터를 읽고, 맞는 설정을 알아서 적용합니다.**
   화면 맨 위에 무엇을 바꿨는지 나오고, 바로 아래에 **원래대로 되돌리기** 버튼이 있습니다.

**두 번째 실행부터는 알아서 바꾸지 않습니다.** 되돌리려고 켠 사람에게 다시 적용해버리면
안 되니까요. 그때부터는 화면에서 상태를 보고 파란 버튼을 직접 누릅니다.

"이 컴퓨터에 맞게" 가 실제로 하는 일:

| 이 컴퓨터를 읽어서 | 이렇게 정합니다 |
|---|---|
| 모니터가 낼 수 있는 최대 주사율 | 지금 해상도 그대로, 그 모니터의 최대 Hz 로 |
| 서든어택이 깔린 곳 (넥슨 폴더·프로그램 목록) | 그 exe 에만 전체 화면 최적화 끄기·우선순위 |
| 이미 되어 있는 설정 | 건드리지 않습니다 (되돌릴 값이 더럽혀지니까) |
| CPU 가 라이젠 9 X3D | 전원 계획을 **바꾸지 않습니다** (아래 3번 참고) |
| 노트북 | 배터리일 때는 CPU 를 100% 로 묶지 않습니다 |
| 그래픽카드 회사 | 'NVIDIA 앱 / AMD / 인텔' 중 해당하는 안내만 보여줍니다 |
| 관리자 권한이 없음 | 자동 적용을 하지 않고 기다립니다 (반쪽만 적용되면 안 되니까) |

되돌리기 기록은 `%LOCALAPPDATA%\SuddenAttackOptimizer\backup` 에 남습니다.
**exe 를 지웠다가 다시 받아도 되돌릴 수 있습니다.**

> V3·알약 같은 백신이 exe 를 막으면: 파이썬 프로그램을 exe 로 묶은 파일은 가끔 오진됩니다.
> 그럴 땐 아래 나) 방법을 쓰세요. 내용은 완전히 같습니다.

### 나) 파이썬이 있으면 — 폴더째

위쪽 초록색 **`Code`** 버튼 → **`Download ZIP`** → **압축을 꼭 풀고**

```
  서든어택 최적화.bat        ⬅ 이걸 더블클릭하세요
  되돌리기.bat                  화면이 안 열릴 때를 위한 비상용
  optimizer.py                  프로그램 (한 파일)
  README.md                     이 문서
  tests/                        자동 검사 (지워도 프로그램은 돕니다)
```

파이썬(3.8 이상)만 있으면 됩니다. 다른 라이브러리는 하나도 안 씁니다.
이 방법은 기록이 폴더 안 `backup/` 에 남습니다.

파이썬이 없으면 배치 파일이 알려주고 설치 페이지를 엽니다. (윈도우에 들어 있는
'마이크로소프트 스토어로 보내는 가짜 python' 도 가려냅니다.)

### exe 는 어떻게 만들어지나

`optimizer.py` 가 바뀌어 main 에 올라오면 GitHub 이 **진짜 윈도우 컴퓨터**에서
검사를 전부 돌리고 → exe 를 만들고 → 그 exe 로 화면까지 실제로 띄워본 뒤 → 통과해야만
Releases 에 올립니다 (`.github/workflows/build-exe.yml`).

## 1. 먼저 — 서든어택은 '프레임'이 문제가 아닙니다

### 네 가지는 서로 다른 것입니다

| 말 | 뜻 | 누가 정하나 |
|---|---|---|
| **프레임 (FPS)** | 컴퓨터가 1초에 **그리는** 장면 수 | 그래픽카드 · CPU · **게임 안 옵션** |
| **주사율 (Hz)** | 모니터가 1초에 **보여주는** 장면 수 | 모니터 + **윈도우 설정** |
| **입력 지연** | 마우스를 움직이고 화면에 나타나기까지 | 윈도우 · 모니터 · 게임 설정 |
| **핑 (ms)** | 내가 쏜 신호가 서버까지 갔다 오는 시간 | 인터넷 회선 + **윈도우 네트워크 설정** |

### 서든어택은 프레임이 남습니다

2005년에 나온 게임이라 요즘 컴퓨터에서는 프레임이 이미 넘칩니다.
그런데 **프레임이 300이든 400이든, 모니터가 60Hz 면 눈에 보이는 건 초당 60장입니다.**
남는 프레임을 더 늘리는 건 아무 의미가 없습니다.

### 그래서 진짜 병목은 셋입니다

| | | |
|---|---|---|
| ① | **모니터가 몇 장 보여주나** | 주사율 — 셋 중 제일 큽니다 |
| ② | **내 손이 화면에 얼마나 빨리 나타나나** | 마우스 가속, 전체 화면 최적화 |
| ③ | **쏜 게 서버에 얼마나 빨리 닿나** | 랜선인지 와이파이인지, 회선이 고른지 — 윈도우 설정보다 훨씬 큽니다. 화면의 '점검' 에서 핑을 재볼 수 있습니다 |

### 숫자로 보면

- **60Hz** — 장면 하나가 **16.7ms** 동안 그대로 멈춰 있습니다. 방금 일어난 일이 화면에 뜨기까지 평균 **8ms** 기다립니다.
- **144Hz** — 6.9ms 라 평균 **3.5ms**.

이 4~5ms 차이는 "반응 속도가 빨라진다" 기보다 **움직이는 적이 끊기지 않고 이어져 보인다**
는 쪽으로 옵니다. 그래서 숫자보다 체감이 큽니다.

### 프레임을 정말 올리고 싶다면

그건 윈도우가 아니라 **게임 안 옵션**입니다. 그림자·효과 끄기, 수직 동기 끄기.
아래 화면 맨 아래 **직접 하셔야 하는 것** 을 보세요. **거기가 제일 크게 갈립니다.**

### 이 프로그램이 손대는 곳

| 어디 | 항목 수 |
|---|---|
| 끊김 (순간 렉) | 5 |
| 핑 | 2 |
| 에임 | 1 |
| 화면 (주사율) | 1 |
| 지연 | 1 |
| 프레임 | **1** |
| 바탕화면 · 방해 · 로딩 | 각 1 |

프레임 숫자를 실제로 올려주는 항목은 **배경 녹화 끄기 하나뿐**이고, 그것도 배경 녹화가
실제로 돌고 있을 때 얘기입니다. 나머지는 지연과 끊김 쪽입니다. 부풀려 적지 않았습니다.

## 2. 화면에서 보이는 것

**맨 위 — 내 컴퓨터**
CPU·그래픽카드·메모리·윈도우 버전·노트북인지 데스크톱인지, 그리고 **모니터가 지금 몇 Hz 로 돌고 있는지**.
`1920×1080 · 60Hz → 최대 144Hz 가능` 처럼 나오면 지금 손해 보고 있다는 뜻입니다.

**가운데 — 한 번에 최적화**
권장 항목 중 아직 안 된 것만 골라서 적용합니다. 이미 되어 있는 건 건드리지 않습니다.

**그 아래 — 이 컴퓨터에서는** ⬅ **여기만 봐도 됩니다**
15개를 다 읽을 필요 없이, **내 컴퓨터에서 실제로 달라지는 것만 큰 순서대로** 나옵니다.
일반론이 아니라 읽어온 진짜 값으로 씁니다.

> **크게** · 모니터 주사율 최대로
> 모니터가 **60Hz** 로 돌고 있습니다. **144Hz** 로 올리면 눈에 보이는 장면이 **2.4배**가 되고,
> 방금 일어난 일이 화면에 뜨기까지 평균 **8.3ms → 3.5ms** 로 줄어듭니다.

이미 되어 있는 것, 잠긴 것, 체감이 작은 것은 아래에 접어둡니다.
**크게 달라질 게 없으면 없다고 말합니다** — 있지도 않은 효과를 팔지 않습니다.

같은 항목이라도 컴퓨터마다 다르게 판정합니다.

| | |
|---|---|
| 모니터가 이미 최대 주사율 | 주사율 항목은 `이미 됨` 으로 내려갑니다 |
| **노트북** | 전원 계획이 `크게` 로 올라갑니다 (CPU 절전 폭이 크니까) |
| **데스크톱** | 같은 항목이 `보통` 입니다 |
| 마우스 가속이 이미 꺼져 있음 | `이미 됨` — 눌러도 달라질 게 없습니다 |

**그 아래 — 점검 (버튼으로는 못 고치는 것)** — 읽기만 합니다

| 점검 | 무엇을 보나 |
|---|---|
| 메모리 | 종류·속도·개수. DDR5 가 4800 이면 **바이오스 EXPO/XMP** 가 꺼져 있을 수 있다고, 1개만 꽂혀 있으면 **싱글 채널**이라고 알려줍니다 |
| 인터넷 연결 | 게임이 나가는 연결이 **와이파이**면 경고. 유선인데 100Mbps 로 잡히면 랜선 의심 |
| 켜져 있는 오버레이 | Discord · NVIDIA 오버레이 · RivaTuner · OBS. **키 씹힘·순간 끊김**이 있으면 먼저 꺼볼 곳 |
| 전원 | 노트북이 **배터리**로 돌고 있으면 경고 |
| 핑 재기 (버튼) | 10번 재서 평균, 가장 빠름/느림, **손실**. 손실이나 흔들림이 있으면 럽샷의 원인입니다 |

**그 아래 — 접혀 있는 설명**
`먼저 — 서든어택은 '프레임'이 문제가 아닙니다` 를 펼치면 위 1번 내용이 그대로 있습니다.

**아래 — 항목 목록**
항목마다 세 줄이 붙습니다.
| | |
|---|---|
| 회색 줄 | **무엇을** 켜고 끄는 건지 |
| 뱃지 붙은 줄 | **체감 큼/보통/작음**, 어디가 좋아지는지(에임·핑·끊김…), 그리고 무엇이 좋아지는지 |
| 주황 줄 | 알아둬야 할 것 (있을 때만) |

체크를 풀면 그 항목은 안 건드립니다. `고른 것만 적용` 으로 원하는 것만 할 수도 있습니다.

**그 아래 — 되돌리기**
마지막으로 언제 무엇을 바꿨는지와 **원래대로 되돌리기** 버튼.

**맨 아래 — 직접 하셔야 하는 것**
게임 안 옵션과 그래픽카드 제어판 설정. 이건 자동으로 못 바꿔서 안내만 합니다.

## 3. 무엇을 바꾸나 — 하나씩

체감 등급은 **부풀리지 않았습니다.** 작은 건 작다고 적어야 큰 게 믿깁니다.

### 🔵 체감 큼 — 이 둘이 사실상 전부입니다

**마우스 가속 끄기** · 에임
> **무엇을** 윈도우가 마우스를 빨리 움직일수록 커서를 더 많이 움직여주는 기능을 끕니다.
> **뭐가 좋아지나** 같은 거리를 움직이면 언제나 같은 만큼 조준이 돕니다. 몸이 감각을 외울 수 있게 됩니다. 프레임은 1도 안 오르지만 **에임에서는 이게 제일 큽니다.**

**모니터 주사율 최대로** · 화면
> **무엇을** 모니터가 1초에 화면을 몇 번 새로 그릴지를 낼 수 있는 최대로 올립니다. 해상도는 안 건드립니다.
> **뭐가 좋아지나** 60→144Hz 면 눈에 보이는 장면이 **2.4배**. 움직이는 적이 뚝뚝 끊기지 않고, 화면에 뜨기까지가 평균 8ms → 3.5ms.
> **이미 최대면** 아무 변화 없습니다. 화면 맨 위에서 지금 몇 Hz 인지 확인하세요.

### 🟡 체감 보통

**전체 화면 최적화 끄기** · 지연
> **무엇을** 윈도우가 전체 화면 게임을 몰래 '테두리 없는 창'으로 바꿔 돌리는 기능을 끕니다.
> **뭐가 좋아지나** 화면이 윈도우를 한 번 덜 거치고 모니터로 갑니다. 대략 한 장면만큼 덜 기다립니다. **느끼는 사람과 못 느끼는 사람이 갈립니다.**
> 실행 파일 '속성 → 호환성' 탭에 이미 걸어둔 것(관리자 권한으로 실행 등)은 **지우지 않고 보탭니다.**

**게임용 전원 계획** · 끊김
> **무엇을** CPU가 한가할 때 속도를 낮추는 절전 동작을 끕니다. 쓰던 계획은 복제해서 새로 만듭니다.
> **뭐가 좋아지나** 평균 프레임보다 **'순간적으로 뚝 떨어지는 것'** 이 줄어듭니다. 노트북이나 오래된 CPU 일수록 큽니다. 최신 데스크톱이면 작습니다.
> **라이젠 9 X3D(7900X3D·7950X3D·9900X3D·9950X3D)는 건너뜁니다.** 이 CPU 는 윈도우 '균형 조정' 계획에서만 AMD 칩셋 드라이버가 게임을 캐시 큰 코어로 몰아줍니다.

**배경 녹화(Game DVR) 끄기** · 프레임
> **무엇을** Xbox Game Bar 의 게임 녹화 기능을 끕니다.
> **뭐가 좋아지나** 이 프로그램에서 프레임 숫자를 실제로 올려주는 거의 유일한 항목입니다. 단 **'지난 30초 녹화'가 실제로 돌고 있었을 때만**입니다. 안 돌고 있었으면 화면에 `조금` 으로 나옵니다.

### ⚪ 체감 작음 — 해서 나쁠 건 없는 것들

| 항목 | 무엇을 | 뭐가 좋아지나 |
|---|---|---|
| **네트워크 지연 줄이기 (Nagle 끄기)** | 작은 신호를 모았다 보내는 기능 끄기 | TCP 신호에만 걸립니다. 서든어택 교전 신호가 어느 방식인지는 공개된 게 없어서 **체감을 약속하지 않습니다** |
| **네트워크 속도 제한 풀기** | 윈도우가 걸어둔 초당 패킷 제한 해제 | Nagle 과 같은 방향, 효과는 그보다 작습니다 |
| **윈도우 게임 모드** | 업데이트·배경 작업 미루기 | 게임 중 윈도우가 갑자기 딴짓하는 일이 줄어듭니다 |
| **서든어택 우선순위 '높음'** | 실행 시 CPU 우선순위 | CPU가 여유로우면 **차이 없습니다** |

### 직접 켜야 하는 것 (기본 꺼짐)

| 항목 | 뭐가 좋아지나 | 왜 기본이 아닌가 |
|---|---|---|
| **윈도우 화면 효과 줄이기** | 창·메뉴가 기다림 없이 뜹니다 | **게임과 관계가 없고** 윈도우 모양이 투박해집니다 |
| **게임에 CPU·GPU 우선 배정** | 게임이 이 등급에 스스로 등록할 때만 | 서든어택 같은 오래된 게임은 대개 등록을 안 합니다. 업체들이 흔히 넣는 값이라 남겨둠 |
| **알림 팝업 끄기** | 결정적인 순간에 화면이 안 가려집니다 | 게임이 아닐 때도 알림이 안 옵니다 |
| **HAGS 끄기** | 프레임 간격이 고르게 나오는 경우가 많습니다 | 컴퓨터마다 다르고, 재부팅 필요. **끄면 다른 게임의 DLSS 프레임 생성이 안 됩니다** |
| **백신 검사 제외** | 맵 첫 로딩의 순간 렉이 줄어듭니다 | 그 폴더는 검사를 안 하게 됩니다. 드라이브 통째·다운로드·바탕화면 같은 **넓은 폴더에는 아예 걸지 않습니다** |

## 4. 일부러 **안** 하는 것

다른 최적화 프로그램들이 흔히 손대는 것들입니다. 빠뜨린 게 아니라, 얻는 것보다 잃는 게
커서 뺐습니다.

| 안 하는 것 | 이유 |
|---|---|
| `bcdedit` — HPET · 플랫폼 클럭 | 잘못되면 **윈도우가 아예 안 켜집니다.** 프레임이 오른다는 근거도 확실하지 않습니다 |
| 가상 메모리(페이지 파일) 끄기 | 메모리가 모자라는 순간 게임이 경고 없이 꺼집니다 |
| 윈도우 서비스 대량 정지 | 소리가 안 나거나 업데이트가 멈추는 식으로 한참 뒤에 조용히 고장 납니다 |
| 레지스트리 청소 · 임시파일 삭제 | 프레임과 관계가 없고, 지운 건 되돌릴 수도 없습니다 |
| 게임 파일 수정 | 게임을 바꾸는 일이라 계정이 막힐 수 있습니다 |
| 메모리 무결성(코어 격리) 끄기 | 무거운 게임에선 몇 % 차이가 나기도 하지만, 서든어택은 프레임이 남아서 얻을 게 없고 방어만 꺼집니다 |
| CPU 보안 패치 끄기 (Spectre·Meltdown) | 요즘 CPU 에서는 성능 차이가 거의 없고 보안 구멍만 열립니다 |
| 타이머 해상도 고정 프로그램 | 윈도우 10(2004) 부터는 다른 프로그램에 번지지 않아서 게임에 닿지 않습니다 |
| 레지스트리 '네트워크 최적화' 값 (TcpWindowSize 등) | 비스타부터 윈도우가 알아서 맞추고 이 값을 읽지도 않습니다 |

## 5. 되돌리기

**바꾸기 전 값을 그대로 다시 넣습니다.** 원래 없던 값은 지웁니다.
"기본값으로 초기화" 가 아니라 **당신 컴퓨터가 원래 갖고 있던 값**으로 돌아갑니다.

| 방법 | |
|---|---|
| 화면에서 | **원래대로 되돌리기** 버튼 |
| 화면 없이 | **`되돌리기.bat`** 더블클릭 |
| 터미널에서 | `python optimizer.py revert` |

기록은 `backup/최적화기록-날짜-시각.json` 에 쌓입니다 (exe 는 `%LOCALAPPDATA%\SuddenAttackOptimizer\backup`,
폴더판은 폴더 안). 바꾸기 전에 **기록을 남길 수 있는 곳인지부터 확인**하고, 항목 하나를 바꿀
때마다 곧바로 적습니다. 기록을 못 남기면 방금 바꾼 것은 그 자리에서 되돌리고 멈춥니다.

두 번에 나눠 적용했으면 기록도 둘입니다. 하나를 되돌리면 "하나 더 있습니다" 라고 알려줍니다.

전원 계획은 **쓰던 계획을 고치지 않고 복제해서** 새로 만듭니다. 되돌리기는 원래 계획으로
돌아간 뒤 우리가 만든 걸 지우는 것이라, 손수 맞춰둔 설정이 사라지지 않습니다.

## 6. 서든어택을 못 찾았다고 나오면

세 항목(전체 화면 최적화·우선순위·검사 제외)은 실행 파일 위치를 알아야 합니다.
넥슨 런처는 설치 폴더를 사용자가 정할 수 있어서 한 곳에 박혀 있지 않습니다.

화면 위쪽 칸에 **설치 폴더나 `.exe` 경로**를 넣고 `찾기` 를 누르면 됩니다.
(예: `C:\Nexon\SuddenAttack`)

찾는 방법: 바탕화면 서든어택 바로가기 **우클릭 → 파일 위치 열기**.

나머지 항목들은 게임 경로를 몰라도 전부 적용됩니다.

## 7. 터미널에서 쓰기

exe 도 같은 명령을 받습니다 (`SuddenAttack-Optimizer.exe status` 처럼).

## 8. 자주 나오는 상황

**Q. 프레임이 그대로인데요**
이 프로그램은 윈도우 쪽 병목만 치웁니다. 프레임 자체는 대개 **게임 안 옵션**과
**그래픽카드 제어판**에서 갈립니다. 화면 맨 아래 `직접 하셔야 하는 것` 을 펼쳐보세요.
특히 **수직 동기 끄기**와 **그림자·효과 낮추기** 가 큽니다.

**Q. 화면이 안 뜹니다**
브라우저 주소창에 `http://127.0.0.1:8770` 을 직접 넣어보세요.
포트가 쓰이는 중이면 8771, 8772… 로 옮겨 뜹니다. 검은 창에 실제 주소가 적혀 있습니다.

**Q. 항목이 잠겨 있습니다 (`관리자 권한이 필요합니다`)**
`서든어택 최적화.bat` 을 **우클릭 → 관리자 권한으로 실행** 하세요.

**Q. 되돌렸는데 화면이 그대로예요**
`윈도우 화면 효과`와 `하드웨어 가속 GPU 일정 예약` 은 다시 로그인하거나 재부팅해야
완전히 반영됩니다. 마우스·주사율·전원은 바로 반영됩니다.

**Q. "Windows의 PC 보호" 창이 떠요 / 백신이 막아요**
exe 판만 해당됩니다. 서명 인증서(유료)가 없는 개인 프로그램이라 뜹니다. **추가 정보 → 실행**.
백신이 지워버리면 0-나) 폴더판을 쓰세요. 코드는 이 저장소에 전부 공개돼 있습니다.

**Q. 윈도우 설정에 '일부 설정은 조직에서 관리합니다' 가 떠요**
2.2 이전 판이 배경 녹화를 끌 때 정책 키를 같이 썼기 때문입니다 (2.3 부터는 안 씁니다).
그때 기록으로 **되돌리기** 하면 사라집니다.

**Q. 키가 가끔 씹히거나 교전 중에만 순간 끊겨요**
화면의 **점검** 칸에 켜져 있는 오버레이가 나오는지 보세요. 디스코드 오버레이가 흔한 원인입니다.
자석축 키보드라면 맨 아래 **키보드 · 마우스** 안내(래피드 트리거는 A·D 에만, 디바운스 최소)를 보세요.

**Q. 이 화면을 다른 웹사이트가 조작할 수는 없나요**
없습니다. 이 컴퓨터에서, `127.0.0.1` 주소로 연 화면에서 누른 버튼만 받습니다. 화면마다 숨겨진
표(토큰)가 있어서, 다른 사이트가 몰래 폼을 보내도 아무것도 하지 않습니다.

**Q. 이거 계정 밴 당하지 않나요**
게임 파일이나 게임 메모리는 전혀 건드리지 않습니다. 윈도우 제어판에서 손으로 바꿀 수
있는 설정들을 대신 눌러주는 것뿐입니다.

## 9. 프로그램 구조 (고칠 분만)

`optimizer.py` 한 파일이 전부입니다. 파일 맨 위에 지도가 있고, 본문은 그 번호대로
`# [1] …` 배너로 나뉘어 있습니다. 편집기에서 `# [` 로 검색하면 목차처럼 훑을 수 있습니다.

| 번호 | 무엇 |
|---|---|
| `[1]` | 레지스트리 — 윈도우 설정값 읽기·쓰기 (+ 검사용 가짜 저장소) |
| `[2]` | 명령 실행 — powercfg · PowerShell · 관리자 권한 |
| `[3]` | 모니터 — 주사율 조회·변경 |
| `[4]` | 컴퓨터 정보 — CPU · 그래픽 · 메모리 · 윈도우, 점검(메모리 속도·연결·오버레이·핑) |
| `[5]` | 게임 찾기 — 서든어택 설치 위치 |
| `[6]` | 되돌리기 기록 — 저장·읽기 |
| **`[7]`** | **최적화 항목 전부 — 항목을 더하고 빼는 곳** |
| `[8]` | 실행기 — 적용·되돌리기, 무엇이 막혔는지 판단 |
| `[9]` | 안내문 — 자동으로 못 바꾸는 것 |
| `[10]` | 화면 — 브라우저 페이지 |
| `[11]` | 시작 지점 — 더블클릭과 명령줄 |

**항목을 추가하려면** `[7]` 의 `catalog()` 에 `Tweak(...)` 을 하나 더 넣으면 됩니다.
레지스트리 값이면 `RegistryAction([RegItem(...)])` 만 쓰면 **되돌리기는 저절로 됩니다.**

윈도우 API를 쓰는 부분은 전부 **가짜로 바꿔 끼울 수 있게** 되어 있어서, 윈도우가 없어도
검사가 돕니다.

```bash
python -m pytest -q
```

검사의 중심은 하나입니다 — 저장소 전체를 통째로 떠놓고, 적용했다가 되돌린 뒤
**손대기 전과 한 글자도 다르지 않은지** 비교합니다.
